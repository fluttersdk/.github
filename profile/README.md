## This organisation has moved

The packages, documentation and snippets now live at [anilcancakir.com](https://anilcancakir.com), and the source is on [github.com/anilcancakir](https://github.com/anilcancakir).

| Package | What it is |
| --- | --- |
| [wind_kit](https://anilcancakir.com/wind_kit) | Tailwind CSS for Flutter: utility-first `className` styling |
| [tapir](https://anilcancakir.com/tapir) | End-to-end driver for a live Flutter app, built for AI agents and CI |
| [crumbs](https://anilcancakir.com/crumbs) | Passive runtime inspector: HTTP, logs, exceptions and queries |
| [dowel](https://anilcancakir.com/dowel) | Composable Dart CLI framework and stdio MCP server |
| [magic](https://anilcancakir.com/magic) | Laravel-style app framework for Flutter (alpha) |
